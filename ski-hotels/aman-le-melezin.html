顶级滑雪酒店 | Aman Le Mélézin，雪山上的宫殿

比利白 · 2018-06-29 · 查看公众号原文 ↗

说起安缦，喜欢酒店与旅行的人是不会陌生的，无数aman junkie满世界的打着卡收集着行李牌，我也不例外。

了解我的朋友一定知道，冬天是我最忙碌的时段，不是在滑雪就是在去滑雪的路上，自然对能滑雪的酒店格外感兴趣。虽说安缦是一家海岛基因强大的集团，依然有两家度假村与雪沾边，一家是位于美国Jackson Hole的Amangani，另一家就是今天的主角，法国Courchevel的Aman Le Mélézin。

对这家安缦的初印象，是几张宣传照，宛若法式古堡的造型，毗邻雪道旁惬意的露台与Hot Tub，一下就令我着了迷。

打听资料的时候才发现，法国的这家安缦，大家都觉得很神秘，甚至不少资深安缦人，都知之甚少。作为一间季节性的滑雪酒店，这座雪山上的安缦确实有着神秘的一面，好在上个冬天终于有幸探访，把滑雪与住店这两个小兴趣融合了一下，今天便结成一篇报告。

1850 / 1992 / 25

认识Aman Le Mélézin（安缦-勒-梅雷赞），请先从念对名字开始。法语名有松林之意的Le Mélézin坐落于高雪维尔1850滑雪场（Courchevel1850），恰巧被一群松叶林围绕。

Courchevel1850是什么地方？作为这世上最奢华的滑雪场之一，我曾专门为这里撰文一篇 探秘高雪维尔1850 | 两万一晚的滑雪酒店长什么样？

核心区域35000欧元（约26万人民币）每平米的房价直指国际一线都市；法国最顶级的24家Palace（宫殿级）酒店中有三家开在这里，3000欧元一晚（约23000人民币）的价格经常要求五晚起订，还总是一房难求。

若是你周遭有几个了解滑雪的欧洲人，不妨问问他们关于高雪维尔1850（Courchevel 1850）的事。答案无非是微笑的点头赞许或者苦笑着摇头，“那是有钱人才去的地方”。

时光回到遥远的1956年，Le Mélézin的原型是Marescal家族运营的Le Savoy酒店。作为酒店的老顾客，安缦创始人Adrian Zecha在1990年直接买下酒店，让Ed Tuttle来主持翻新工作。受到中世纪城堡启发的Ed Tuttle将这里打造成了一座不折不扣的雪山宫殿，也是他继Amanpuri，Amankila后为安缦设计的第三间作品。

1992年法国阿尔贝维尔冬奥会之后的12月，全球第五家安缦酒店Aman Le Mélézin如期开张，并在Courchevel1850最著名的Bellecôte雪道旁驻立了二十五年，接待名流无数。

高雪维尔1850毕竟不是等闲之地，Ed Tuttle的设计也许不会过时，但周遭的竞争让安缦感受到了压力。前有三家Palace宫殿级酒店（2011年开业的K2 Palace，同样1992年开业但经过2007年大幅翻修的Les Airelles以及2006开业就集万千宠爱于一身的白马Cheval Blanc Courchevel），后有2016年底崭新开业的隔壁邻居，法国娱乐届巨头Barrière集团的Barrière Les Neiges在一旁虎视眈眈。对已经25岁的Le Mélézin来说，重新翻修势在必行。

经历了2016，17两个夏天的重新整修后，Le Mélézin翻新了19间客房，甚至向下挖了几层，完成了全新800平米的水疗设施。新翻修后，整个风格呈现出浓浓的禅意，好几次我差点产生了来到安缦东京的错觉。亚洲人喜爱的法式城堡加上令欧美人着迷的东洋和风，给1850带来了新潮流。关于这次的翻修的力度，用我在1850熟悉的滑雪教练Pierre的话说，这简直不是我印象中的Le Mélézin，法国人很开心。

穿越：从高雪维尔到东京

相比世界各地那些难以抵达的安缦酒店，到达安缦Le Mélézin的方式很简单，从滑雪场中心步行数分钟，或从雪道上直接滑进酒店。在高雪维尔1850这个大秀场，安缦虽然凭借其宫殿般的外观圈粉无数，却依旧保持其一贯的低调，连logo都安置的很不起眼。与之相对的，是Arnault宅子门口那硕大的闪亮白马。

进入大门，我就一下从萨瓦山村穿越到了东洋。仔细找找酒店里的日本元素有多少呢？大堂处设置的巨型盆栽，角落一处迷你的日本庭院，房间的日式卫浴，新开业的日本料理餐厅，直到我走入瑜伽房的那一刻，确定迷失在了东京。

拉我回过神来的是一口熟悉的法式英语。组成这家安缦服务队伍的是一群年轻热情的小哥，作为雪山上的度假村，着装也十分运动时尚，各位女士要保持理智啊。

自然派客室

仅有的31间客房在经过翻修后，并没有丢失当年Ed Tuttle的自然派设计，大量使用橡木甚至象牙等材料，雪松木天花板搭配淡色系的织物，配上窗外雪山的美景格外动人。

最小的Junior Room只有22平米，因此我相对比较喜欢宽敞些的Chambre Mélézin和Chambre Ski Piste with Hot Tub，40平左右的这两种房型都直面雪道，特别符合那些想站在阳台上看面前滑雪者飕飕飞过的人们，更不要说在大露台上泡Hot Tub了。

有多少人被这个Hot tub圈粉啊

除了上面提到的几种房型外，38平米的Chambre Village与不带Hot tub的Chambre Ski Piste也比较合适，若是人数较多，不妨考虑一下最多五人入住的家庭房Family Apartment。至于那几个大套房，不出点血是拿不下的。

房间的一些小细节值得玩味，和安缦东京一样的崭新Bose蓝牙音箱，时尚设计感的迷你吧，比日本都高科技的卫洗丽马桶。

门上还会有萨瓦地区特有的marmotte挂件，再一次宣誓了地理身份

NAMA / AMAN

说到了日本元素，自然离不开和食。Le Mélézin有一间日式餐厅——NAMA，提供纯正日本料理。说说这个名字吧，真的很有意思，NAMA是汉字“生”的日语发音，也是AMAN的倒序排列。2017年初，主厨Keiji Matoba操刀的第一家NAMA餐厅开在了普吉岛的Amanpuri，随着这次成功拓展，估计今后也会推广至其他安缦度假村之中。

本地的新鲜食材搭配日本空运的原材料，竟也能在雪山上吃到正宗的日本料理了，不知道欧洲客人会不会和我一样为了滑雪后的一碗拉面而满足呢。仔细注意一下，墙上的艺术品都是员工从日本带过来的。

值得一提的是，Le Mélézin于2013年被Lov Collection集团收购，后者也拥有1850另一家顶级酒店Les Airelles，因此入住安缦的客人也能在Les Airelles用餐，算是很好的联动。

滑雪，才是正经事

对于这样一间每年只营业四个月的季节性酒店来说，滑雪，才是正经事。说到底，Courchevel 1850能吸引全世界的名流贵族来此度假，还是源于滑雪本身。作为世界上最大的滑雪区域三山谷Les Trois Vallées的重要组成部分，高雪维尔1850永远是三山谷最闪耀的一颗明珠。虽然奢华酒店与高档餐厅鳞次栉比，只合四百多人民币的雪票就能畅滑一天了。

1850的每家五星酒店都一定自营或合作自己的滑雪商店，租装备这种事情绝不可能让客人跑腿。安缦也不例外，重新装修的雪具室宽敞明亮，每天早上你的雪鞋手套一定被烘干到暖和，不劳自己动手，至于雪板们，已经在直通雪道的门口按房间号整齐排列好了。当然，同时等候的还有一口法式英语的教练们。

1850式的滑雪度假

滑雪又不是高雪维尔的全部，Courchevel 1850代表的滑雪度假方式，其精髓不是滑雪之余可以干什么，而是度假之余还能滑雪。虽说房费包含了酒店内极好的半食宿，但对于想出去换换口味的人，还有不少选择。

在罗莱夏朵成员Chabichou酒店内，Michel Rochedy的传奇餐厅保持米其林两星已经长达34年，而白马酒店也靠Yannick Alléno坐镇，餐厅Le 1947成功在2017年米其林指南中拿下三颗星。7间米其林餐厅分享了12颗星星，不仅冠绝世界雪场，也可能是全法国星级餐厅密度最高的地方。

致不滑雪的人们，购物去吧。核心区域的购物街上是LV、爱马仕、宝格丽的精品店，也有贵到惊人的高定时装和名贵珠宝，在这里，奢侈品的密集程度远超巴黎。购物之余，还能欣赏俄罗斯女选手带来的世界貂皮展览。买好东西自然会送到你所住的酒店里，什么？那些不住在Courchevel的客人，送你一个背包，背着爱马仕滑回家吧。

Courchevel 1850的高山机场凭借其起降难度享誉世界，来自俄罗斯和全世界的富豪们习惯搭乘私人飞机空降雪场。没有私人飞机，体验不了闪亮登场的感觉，亦有便宜的选项，坐直升机小转一圈。从上帝视角俯视雪场，或者飞远点看看勃朗峰，也是不错的选择。

好动的，可以玩玩狗拉雪橇，雪地摩托，晚上去夜店看一掷千金的俄国大亨与来自东欧的长腿美女们。好静的，就留在酒店做个SPA美个容，安缦全面重新装修的SPA中心，泳池与瑜伽房充斥着满满的禅意，和不远处的K2 Palace酒店一起组成了1850的神秘的东方力量。

当然这一切都不劳烦你受冻担心滑到，想出门逛逛，随叫随到的豪车是酒店标配。

大堂的Lounge是休憩和欣赏雪景的好去处，绅士们则可以躲在雪茄室里免受打扰，这里可是有从多米尼加Amanera带来的顶级雪茄，不禁再一次感叹分店多就是好。

Aman Le Mélézin的价格在1850的奢华酒店中还排不到最贵的那档，但相比其他目的地的安缦酒店，由于季节性运营的特殊性，平均房价要更贵一些。最便宜的Chambre Junior起价在1100欧元每晚，我个人喜欢的Chambre Ski Piste则需要2250欧元（带Hot tub的房型为2600欧元），好处是上述价格都包含了半食宿，客人可以选择早餐+午餐或者早餐+晚餐的方案。

由于滑雪场酒店的特殊性，为了让客人有一个更好的体验，安缦往往有最低五晚的起订要求。这类规定在欧洲的滑雪场亦是主流，高端酒店大多建议至少三晚起订，而木屋则需要成周的租赁，非大家想当然的一两日体验之旅。对于喜爱滑雪的人士，这不会成为困扰，若是只想打卡酒店，可能会有些难办，不妨趁着这个机会，给自己一个学习滑雪的机会，在世界最好的雪场与酒店，体验难忘的滑雪度假。

经过重新翻修，Aman Le Mélézin将以其独特的和洋风，在高雪维尔掀起一股新风潮，也成为了下一家Palace宫殿级酒店的有力竞争者。

我们习惯了东南亚的奢华度假村，却对法国雪山不甚了解，而高雪维尔的从业者们经历了英国名流，俄国富豪，也开始对遥远的亚洲市场充满了好奇，什么是适合中国人的滑雪度假，也许即将在下一个十年成为阿尔卑斯最有趣的话题之一。
