REVIEW IN CONTEXT

说清楚「哪里」，
讨论才有上下文。

LanReview 是自托管的局域网评审工具。上传内容后，成员可以查看材料、在对应位置发表评论并回复；文件副本和评论保存在托管电脑。

01 / TEXT

选中文字

在 Markdown 或可信 HTML 中将意见关联到原文。

02 / IMAGE

标记画面

对图片或视频画面标记位置，再补充具体意见。

03 / TIME

定位时间

在音视频中标记时间点或时间段，便于回看。

CURRENT BOUNDARIES

在可信局域网使用。

项目仍在开发中，跨设备和真实触屏验收尚未完成。HTML 只应使用可信来源；文件副本和评论保存在托管电脑。
